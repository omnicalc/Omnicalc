# 🚀 OmniCalc Ultra - 20-in-1 Professional Tool Hub

OmniCalc is a powerful, mobile-friendly multi-tool web application designed for professionals and students. It combines 20 essential calculators into one lightweight interface.

## ✨ Key Features
* **20-in-1 Utility:** Includes Finance, Marketing, Science, Health, and Math tools.
* **Dual Language Support:** Easily switch between English and Sinhala.
* **Ultra Lightweight:** Fast loading even on slow internet connections.
* **Privacy Focused:** No data is stored; all calculations happen locally on your device.

## 🛠️ Tools Included
1. **Finance:** USD to LKR Converter, Crypto Profit, Loan EMI, VAT/Tax, Discount, Tip Calc, Simple Interest.
2. **Marketing & Business:** CPM, CTR, ROI, Profit Margin.
3. **Science:** Molarity, Dilution, Molecular Weight.
4. **Health:** BMI, Daily Water Intake.
5. **General Tools:** Inch to Cm, Km to Miles, Fuel Cost, Square Root.
